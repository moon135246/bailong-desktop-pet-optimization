# 修复素材备选包

原项目及角色素材作者：**jingh12312-rgb**。原仓库为 https://github.com/jingh12312-rgb/bailong-desktop-pet ，原始素材来自其 v0.5.1 Release。本文记录 **Joseph-Blue 优化分支**提供的局部透明度清理素材；moon135246 的 Windows 分支使用该素材，不将角色创作或这批 Alpha 清理归为自身成果。

## 替换范围

| 动作 | 播放文件 | 帧数 | 帧率 | 时长 |
| --- | --- | ---: | ---: | ---: |
| idle | `修复WebM/idle.webm` | 96 | 24 FPS | 4 秒 |
| idle2 | `修复WebM/idle2.webm` | 96 | 24 FPS | 4 秒 |
| drag | `修复WebM/drag.webm` | 96 | 24 FPS | 4 秒 |
| landing | `修复WebM/landing.webm` | 48 | 24 FPS | 2 秒 |

四段来自用户指定的 2026-11-07 修复 PNG 序列，保留 720×720、24 FPS、帧数及透明通道，使用 libvpx-vp9 / yuva420p / CRF 18 编码为高质量有损 WebM，不缩小分辨率、不重新修边。原始修复 PNG 和 APNG 保留。四段由 187.3 MB 压缩至约 13.9 MB；其余 31 段继续使用作者原始 WebM。完整素材包约 156.8 MB。

原修复仅调整 PNG 的 Alpha；这次 WebM 编码包含颜色空间转换和有损压缩，不宣称与 PNG 的 RGB 逐像素一致。最高播放画质仍为 720×720，默认设置为 512×512。

素材清单只更新四段的 `playbackFile`，保留动作时长、渲染比例、位置偏移和原始来源文件名。现有播放器通过 FFmpeg 的 libvpx-vp9 解码为 RGBA，保留透明背景；原始 35 段素材包单独保留，所有构建脚本默认使用修复包，原始包保留供手动选择。

上游说明：修复方法参考 xiamoqingliang/bailong-codex-pet 的 alpha-cleanup 思路，由 Joseph-Blue 分支独立实现，未复制其修复成品。Windows 分支另行进行了 336 帧对照及应用自检，见 [本分支验证记录](WINDOWS_VALIDATION.md)。

## 使用

下载 [修复备选 Release](https://github.com/Joseph-Blue/bailong-desktop-pet-optimization/releases/tag/v0.5.1-opt.assets.repaired.2) 中的 `bailong-repaired-v0.5.1-assets.zip`。它包含完整的 35 段播放素材和对应清单，可直接用于构建。

先退出桌宠，将现有 `outputs/白龙桌宠素材` 改名保留，再把备选 ZIP 中的 `outputs/白龙桌宠素材` 放到同一位置。不要只复制四个 WebM 而漏掉清单。恢复原版时换回原文件夹即可。构建脚本默认将原版或旧 APNG 修复清单切换为 WebM 修复包清单，保留已有原始动画；修复清单及引用文件齐全后不联网。若要用原版构建，换回原版目录后，同时设置 `ASSET_RELEASE_TAG=v0.5.1-opt.assets.1` 和 `ASSET_FILE_NAME=bailong-original-v0.5.1-assets.zip`。

公开附件支持匿名下载；受限资源仍需相应访问权限。原作者的素材说明和许可边界继续适用；详见 [ASSETS.md](../ASSETS.md)。

## 应用图标

Windows EXE 和 macOS App 使用同批修复 `idle/0001.png`，以原样 PNG 保存于 `app/icons/repaired-idle.png`。构建脚本生成多尺寸 ICO／ICNS 并交给 PyInstaller；只进行系统图标所需的尺寸缩放，保留透明背景。应用图标独立于用户选择原始包还是修复备选包。

## 重新编码

从已有修复 PNG 序列编码单个动作（`%04d.png` 从 0001 开始）：

```bash
ffmpeg -framerate 24 -start_number 1 -i /path/to/repaired/idle/%04d.png -an -c:v libvpx-vp9 -pix_fmt yuva420p -b:v 0 -crf 18 -deadline good -cpu-used 2 -row-mt 1 -threads 4 /path/to/encoded/idle.webm
```

编码使用包含 VP9 编码器的 FFmpeg；随应用分发的精简版只负责播放解码。其余三段使用同样参数，不加缩放滤镜。
